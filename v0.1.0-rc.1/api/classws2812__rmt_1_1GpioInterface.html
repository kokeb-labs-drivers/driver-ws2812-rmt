Detailed Description

template<typename Derived>
class ws2812_rmt::GpioInterface< Derived >

CRTP base of the platform port.

The base declares no hook itself (a forwarding hook would turn a missing override into infinite recursion); the driver checks your class with the Ws2812RmtPort concept.
