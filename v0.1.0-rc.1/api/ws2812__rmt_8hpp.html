Detailed Description

WS2812_RMT driver: the one header to include.

ws2812_rmt::Ws2812Rmt<Port, PixelCapacity> drives a strip of single-wire addressable LEDs (WS2812, SK6812 and compatible) through a port that sends a timed bit stream (on ESP32 the RMT peripheral). It owns the pixel and wire buffers (fixed capacity, no heap), builds the byte stream, resolves the waveform from the datasheet windows and the port's real tick rate, and checks arguments. No SDK, no heap, no exceptions, no lock.
