Detailed Description

The port of the WS2812_RMT driver: the CRTP base, its pin enums and the Ws2812RmtPort concept. The part is driven by a timed bit stream (bus: [pio]), and the port is the only place that touches an MCU peripheral (on ESP32 the RMT transmitter).

The driver builds the byte stream and resolves the waveform; the port sends it. Derive your class from ws2812_rmt::GpioInterface<Self> and implement, all noexcept (the contract of each hook is in docs/porting.md):

  • bool EnsureInitialized(): required; open the channel, idle LOW, drive Power INACTIVE first.
  • bool ResolutionHz(uint32_t& hz): required; the tick rate the channel really runs at.
  • bool Transmit(std::span<const uint8_t>, const Waveform&, uint32_t timeout_ms): required; one gapless stream, then the reset low; false on a failure, a timeout or an underrun it can see, leaving the line low (the driver then waits a full reset before the next frame).
  • void DelayUs(uint32_t): required; wait with the line low.
  • bool GpioSet(CtrlPin, GpioSignal): optional; Power ACTIVE switches the strip supply on. A port with the hook starts unpowered (the application calls PowerOn() before the first Show()); a port with the hook but no pin returns true.
  • void Log(LogLevel, const char*): optional; plain text, never a format.
